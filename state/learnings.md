# Learnings for the hourly desk runs

Read this before choosing stories. The weekly numbers report rewrites it every week (latest:
`reports/weekly-2026-11-10.md`). Tags: **[data]** = Instagram numbers; **[reviewer]** = the blind reviewer's score
cuts; **[schedule]** = how posts went out. Follow it unless it clashes with a RUNBOOK hard rule; the RUNBOOK wins.

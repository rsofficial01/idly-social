## Notes for the setup

- No `add_repo` tool was available in this session. The repo was already cloned, and `main` was checked out from
  `origin/main`.
- `python3` (3.11) imports `requests` but not Pillow's `Image` (it picks up a 3.13 build), so the pipeline and cardkit
  ran on `python3.13`. Playwright was installed for it from the downloaded wheel plus `pyee` and `greenlet`, and
  rendering used `CARDKIT_CHROME=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome`.
- Wikimedia Commons still rate-limits this container (HTTP 429). Plain `list=search` queries mostly work if they're
  15+ seconds apart. Unsplash images (`images.unsplash.com`) download fine.
- `--slot` only accepts am/pm, so this post is recorded as `2026-11-10 am`, like #1710 and #1716.
